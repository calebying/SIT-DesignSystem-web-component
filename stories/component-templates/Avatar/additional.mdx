## Image, with automatic fallback on load error

Set `src` (and `alt`) to show a photo. If the image fails to load — a broken URL, a network
error — the avatar automatically falls back to `initials` (or the generic person icon if
`initials` is also unset), and emits `sit-error` once the fallback has happened.

<Canvas of={AvatarStories.WithImage}>
  <Story of={AvatarStories.WithImage} />
</Canvas>

## Deterministic fallback colours

When there's no image, the fallback background colour is picked deterministically from a hash of
`initials` (or `alt` if `initials` is unset) — the same person always gets the same colour across
renders and page loads, the same way GitHub/Slack-style avatar colouring works. The hash picks
from the 8 `--sit-{variant}-surface-default` colour families `sit-badge`'s `variant` prop also
uses (`primary`, `accent`, `success`, `danger`, `warning`, `cyan`, `purple`, `neutral`).
