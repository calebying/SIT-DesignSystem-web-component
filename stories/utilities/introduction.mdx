# Sit Utility

Sit utility provides CSS class utilities powered by Tailwind generator. It offers a convenient way to apply design tokens and styling directly through utility classes in your HTML.

## What is Sit Utility?

Sit utility classes are:

- **CSS class utility tokens** powered by the Tailwind CSS generator
- **Prefixed with `sit:`** to ensure specificity and prevent CSS naming conflicts
- **Stripped of Tailwind's default stylings** and fully powered by Sit CSS variable tokens, ensuring consistent design system adherence

This approach allows you to leverage utility-first CSS with Sit design tokens while maintaining design consistency across your application.

## Setup instructions

1. **Install the package:**

   ```bash
   npm install @govtechsg/Sit-web-component
   ```

2. **Configure Tailwind CSS:**

   Follow the [Tailwind CSS installation guide](https://tailwindcss.com/docs/installation/framework-guides) for your framework.

3. **Import Sit CSS files:**

   ```css
   // Import theme and foundation files
   @import '@govtechsg/Sit-web-component/themes/day.css';
   @import '@govtechsg/Sit-web-component/themes/night.css';
   @import "@govtechsg/Sit-web-component/css/Sit.css";
   // Import utility styles
   @import '@govtechsg/Sit-web-component/css/utility.css';
   ```

## Using Sit utility tokens

Once installed and configured, you can start using Sit utility classes in your application:

```html
<!-- Example: Using Sit utility classes -->
 <div class="sit:bg-surface-raised sit:p-lg sit:mb-md">
      <h3 class="sit:text-default sit:mb-sm">Card with Default Text</h3>
      <p class="sit:text-subtle sit:mb-sm">This is subtle text for secondary information like descriptions or metadata.</p>
      <p class="sit:text-muted">This is muted text for tertiary content or less important details.</p>
    </div>
```

All utility classes follow the `sit:` prefix convention and are fully supported by Sit CSS variables, ensuring a seamless design system experience.

## Other available utilities

Sit supports all standard [Tailwind CSS utilities](https://tailwindcss.com/docs) with the `sit:` prefix. Examples include: `sit:flex`, `sit:justify-center`, `sit:align-self`,`sit:cursor-pointer`, and many more. For a complete reference of all available utilities, refer to the [Tailwind CSS documentation](https://tailwindcss.com/docs).
